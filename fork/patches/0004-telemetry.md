# 强制关闭项目遥测

t2code 的生产入口均关闭本项目向外发送的产品用量统计、代理反馈、T3 Connect 客户端链路追踪和 OTLP 导出。旧设置与显式开启的环境变量无法重新开启这些功能。本地诊断日志照常保留。

### 同步检查

- 检查 Electron 主进程、桌面启动的服务端、独立 CLI 和内嵌浏览器客户端。手动 OTLP 探测与代理反馈的禁用状态须同时反映在服务端和能力声明里。
- Web 和移动端避免把分析身份附加到连接请求。保持认证、授权、配对和协议协商。检查 Clerk 两端 SDK、移动端启动与崩溃上报和 OTA 配置。
- 模型提供商客户端、官方客户端和官方托管服务各自管理遥测。使用远端进程时，确认它是已更新的 fork 可执行文件。

### 冲突与移除条件

上游增加导出端、试连按钮、SDK 或新启动入口时，沿实际联网边界核对。只有通用配置对生产入口全部生效，且覆盖环境变量、已保存配置与手动请求，才可替换相应补丁。

### 验证

直接启动候选归档里的独立服务端，显式开启遥测环境变量并配置回环收集器。确认服务正常启动、环境描述接口报告反馈与 OTLP 探测关闭、收集器收到零请求。对桌面端和服务端回归测试，也提供旧设置与启用变量并确认本地日志正常写入。
