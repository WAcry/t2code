# 修复分栏集成后的翻译和浏览器测试

分栏 PR 与已发布 nightly 合并后，文件数量的可访问性标签缺少译文。浏览器测试从共享草稿状态读取其他测试留下的数据时，也会把原本分给当前会话的快捷键分给无关草稿。标签条的布局测试需按 CSS 布局像素核对位置，避免 Chromium 的分数缩放产生 1 像素误差。

### 同步检查

保留对应标签的现有译文，并让快捷键测试自行设置和恢复草稿状态。新增或迁移分栏组件时，沿实际调用点检查标签含义、翻译目录和测试夹具。

### 冲突与移除条件

优先采用上游或新版 PR 的译文与测试隔离实现。上游等效修复已覆盖当前测试和组件时，可删除这个补丁。

### 验证

运行 Web 翻译目录校验。先运行 ChatView 再运行 Sidebar 的 Chromium 测试，核对草稿优先排序、跳转编号和终端快捷键场景。用 `SurfaceHost.browser.test.tsx` 核对切换标签时的连接位置。
